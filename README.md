## Install

1. Download [luma-lyrics.js](https://github.com/Altertone/Luma-Lyrics/releases/latest).
2. Move it into your Spicetify Extensions folder.
3. Run:

   ```bash
   spicetify config extensions luma-lyrics.js
   spicetify apply
   ```
